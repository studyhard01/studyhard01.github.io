개인정보처리방침

Autosend SMS Inbox · 작성일: 2026년 10월 11일

서비스 소개개인정보처리방침이용 안내

1. Gmail에서 조회하는 정보와 이용 목적

계정 소유자의 동의를 받아 Gmail 읽기 전용 권한(gmail.readonly)을 사용합니다. 계정 이메일 주소를 확인하고, 최근 30일 받은편지함에서 문자 자동전달 제목에 해당하는 메일의 제목·발신자·수신자·본문·수신 시각·메일 식별자를 조회합니다. Gmail 읽기 권한 자체는 메일함 전체를 읽을 수 있는 범위이지만, 프로그램은 문자 자동전달 메일 조회에 사용합니다.

메일의 발신·수신 계정, 문자 자동전달 제목과 본문 형식, 등록된 전화번호 일치를 확인합니다. 조건에 맞는 문자의 전화번호·본문·수신 시각·메일 식별자 및 웹에서의 확인 상태를 업무 서버에 저장하여 새 문자 알림, 연락처별 문자 내역, 배정대기 목록을 제공합니다. 일반 메일과 등록된 번호에 해당하지 않는 문자는 업무 DB에 저장하지 않습니다.

2. 이용자가 등록하는 업무 정보

이용자가 입력하거나 가져온 연락처의 이름·전화번호·그룹·직종·지역·주소·메모, 배정 정보 및 문자 발송 내역을 연락처 관리와 업무 기록을 위해 저장합니다. 문자 내용과 수신자를 이용자가 확인한 뒤 발송 요청을 수행합니다.

3. 저장 및 서비스 제공 업체

업무 정보와 Gmail에서 가져온 문자 내역은 Google Cloud의 미국 서부(us-west1) 서버에 보관합니다. 서비스 접속은 HTTPS와 로그인을 사용하며, Gmail 연결 토큰은 서버 설정 파일에 제한된 접근 권한으로 보관합니다. Google·GitHub 계정 비밀번호를 저장하지 않습니다.

서비스 직접 문자 발송을 이용하면 이용자가 확인한 수신 전화번호와 발송할 문자 내용이 SOLAPI에 전달됩니다. 휴대전화 문자앱을 사용하는 경우 선택한 수신 번호와 문자 내용이 단말의 문자앱으로 전달됩니다.

이 안내 사이트는 GitHub Pages에서 제공합니다. GitHub Pages는 보안 목적으로 방문자의 IP 주소를 기록합니다. 이 안내 사이트에는 업무 연락처나 문자 내용을 게시하지 않습니다. GitHub Pages의 데이터 수집 안내

4. Google 사용자 데이터 사용 제한

Google에서 얻은 정보는 이용자가 요청한 문자 확인과 업무 관리 기능을 제공하는 데 사용합니다. 해당 정보를 판매하거나 광고 타기팅·신용 평가·범용 AI 모델 학습에 사용하지 않습니다. 권한 있는 이용자가 본인의 업무 문자 내역을 확인할 수 있습니다. 개발·지원 담당자의 내용 확인은 이용자가 해당 내용의 확인을 별도로 요청하거나 보안 대응 등 Google 정책이 허용하는 경우로 제한합니다.

Autosend SMS Inbox의 Google API 정보 사용과 다른 앱으로의 전달은 Google API Services User Data Policy의 Limited Use 요구사항을 준수합니다.

5. 보관과 삭제

업무 내역은 이용자가 확인하고 관리할 수 있도록 보관합니다. 현재 문자 업무 내역의 자동 삭제 기한은 설정되어 있지 않으며, 연락처를 삭제해도 기존 배정·문자 내역은 자동으로 삭제되지 않습니다. 삭제를 원하면 아래 문의처로 요청할 수 있으며, 운영자가 요청자의 권한과 삭제 범위를 확인한 뒤 처리합니다.

장애 복구를 위해 업무 DB의 자동 백업 최근 14개를 보관합니다. 업무 DB에서 삭제한 정보도 백업이 교체될 때까지 백업에 남을 수 있습니다. Gmail 권한을 취소하면 새 메일 조회가 중단되며, 이미 저장한 업무 내역의 삭제는 별도로 요청해야 합니다.

Gmail 계정 소유자는 Google 계정의 연결된 앱 설정에서 언제든지 Autosend SMS Inbox의 접근 권한을 취소할 수 있습니다. 정보 열람·수정·삭제, 연결 정보 삭제 및 개인정보 관련 문의는 hsh__0326@naver.com으로 연락해 주세요.
